### About Me

Hey! I'm **mstlvc**, a full-stack developer and Computer Science student. I craft modern web applications, interactive frontend experiences, intelligent scrapers, and low-level desktop utilities.

- **Currently Building**: Expanding **[Radiance](https://github.com/mstlvc/Radiance)** – a high-performance Windows digital vibrance and display control suite.
- **Featured Projects**: Built **[Radiance](https://github.com/mstlvc/Radiance)** (Windows display & vibrance suite), **[Personal Portfolio](https://github.com/mstlvc/Personal-Portfolio)** (fluid Nuxt 4 showcase at [mstlvc.xyz](https://mstlvc.xyz)), **[Cashboard](https://github.com/mstlvc/Cashboard)** (microtask rewards aggregator at [mycashboard.app](https://mycashboard.app)), and **[3DtoASCII](https://github.com/mstlvc/3DtoASCII)** (3D mesh to terminal ASCII rasterizer).
- **Core Specialties**: Frontend Architecture, Full-Stack Web Apps, API Integrations, Web Scraping, Desktop Tooling, and Server Automations.
- **Philosophy**: Clean code, zero bloat, intuitive micro-interactions, and software that feels instant.
- **Get in Touch**: Open for collaboration, contracting, or technical discussions at **[contact@mstlvc.xyz](mailto:contact@mstlvc.xyz)**.
